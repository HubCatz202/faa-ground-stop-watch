# FAA Ground Stop Watch

Live timeline and trending topics for the FAA nationwide ground stop of 13 November 2026.

- `index.html` is the whole app. Pushing to `main` redeploys it through GitHub Pages.
- `data.json` on the `data` branch holds the entries, topics and status. It is rewritten on every refresh and the page re-reads it about once a minute.

Summaries are written by Claude from public reporting and public posts. Made by HubCatz202 and Claude Fable 5.2.
